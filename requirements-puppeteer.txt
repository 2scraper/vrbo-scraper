# Puppeteer engine, via pyppeteer.
#
#   pip install -r requirements.txt -r requirements-puppeteer.txt
#
# pyppeteer downloads its OWN Chromium on first run. Pointing it at an
# installed Chrome is worth doing — a more faithful client — but it is not
# the gate an earlier version of this file claimed: the two builds
# interleaved on a clean address were served 12 of 12. Point it anyway:
#
#   python3 puppeteer_scraper.py --chromium-path "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" ...
#   python3 puppeteer_scraper.py --chromium-path /usr/bin/google-chrome ...
#
# It warns about this before the run rather than after a blocked page.
#
# Note: pyppeteer pins pyee<12 and urllib3<2.0, which conflict with playwright
# and selenium respectively. Use a separate virtualenv for this engine.
#
# pyppeteer is also effectively unmaintained and its own README points at
# Playwright. It exists here so the family has three drivers behind one row
# schema, not because it is the better choice.
pyppeteer>=1.0.2
